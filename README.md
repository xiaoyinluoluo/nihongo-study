# 日和 · 个人日语学习 MVP 0.2

运行：在本目录执行 `npm run dev`，打开 http://127.0.0.1:4174。Node.js 18+，无需安装依赖。`npm run check` 检查 JavaScript 语法。

包含今日目标、单词添加与翻卡复习、语法笔记、实际学习记录、JSON 备份导出和 AI 老师待配置页面。支持手机布局。初始三个 N5 示例单词，统计从零开始。复习间隔固定为 1/3/7 天，尚未实现自适应间隔算法。每日任务由用户手动勾选。

数据保存在浏览器 localStorage，按上海日期记录。换浏览器或清除网站数据会失去本地记录；请导出备份。当前未实现备份导入、跨设备同步、登录、真实 AI、听力和自动计划。

## 后续云端接入

`database/schema.sql` 提供 Supabase 表结构和按用户隔离的 RLS 策略，尚未执行迁移。云端接入需创建 Supabase 项目、配置登录并替换本地读写层；禁止在前端放 service-role 密钥。

AI 接口建议：服务端 `POST /api/teacher` 接收 `{ message }`，验证用户身份，从数据库读取该用户最近 10 条学习记录、相关词汇和语法，调用模型后返回 `{ reply }`。上下文以学习数据处理，不能作为系统指令。配置 API 密钥仅存服务端环境变量；限制请求长度、调用频率和预算，并记录失败状态。当前静态服务器未实现这个端点。

项目文件：`index.html` 页面骨架、`style.css` 样式、`app.js` 本地数据与交互、`server.mjs` 本地预览、`database/schema.sql` 云数据库预案。

## MVP 0.2：假名基础与交流目标
新增 66 张平假名清音/浊音热身卡、3 个固定口语场景（每个 2 轮）、2 篇入门短文及理解题。每日目标为假名、词汇、口语和阅读。原有本地数据保持兼容。
口语支持浏览器麦克风录音、回听及自评；录音最长 60 秒，仅在当前页面内存中保留，切换页面清除，不上传、不进入备份。设备朗读只选本地日语语音，无可用语音时提示改用文本。尚未实现语音识别、发音评分和自由 AI 对话。当前只包含平假名热身，后续补充片假名、半浊音、拗音、促音和长音。
学习记录新增 kana/speaking/reading 类型；如果已部署旧数据库，需另外迁移 learning_logs 的 type 检查约束。语法笔记仍可使用。


目标路线：假名熟悉 → 带提示的日常短句 → 不看提示的场景回答 → 日常短文 → 更长的真实阅读。目标是日常交流与阅读理解，当前内容只覆盖入门样例，不代表完整课程或水平认证。
